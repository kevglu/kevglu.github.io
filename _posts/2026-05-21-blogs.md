I wrote the second chapter of my dissertation around 2019-2021. The Matlab code has been sitting in my Dropbox folder ever since. The code is a typical scientific haystack with dozens of different variants, unused old files, commented out code fragments and cursing ("bullshit"). Let claude.ai do the hard work and translate it to a nice well-behaved python program.


## The beginning 26-05-21

I got a 20 EUR claude Pro license. Initially I let claude analyse the whole codebase `/init` but I stopped the process because the codebase contains too many dead files. Instead I told claude to focus on two main files and work backwards from there. The initial interpretation of my codebase was quite good. Claude understood the pipeline and even figured out how parameters are set (calibration).

But, claude seems to have problems understanding the link between quantitative assumptions and code, i.e. a near zero standard deviation essentially turns off a stochastic shock. Claude interprets the effect as "small". 
It seems that the "quantitative gut feeling" remains an edge of macroeconomists over LLMs (so far).
